# Warren Buffett and Charlie Munger SEC Filings Analyzer

This project aims to analyze SEC filings of publicly traded companies based on the investment principles of Warren Buffett and Charlie Munger. It extracts data from filings, applies a defined analysis logic, and provides a scoring/recommendation to highlight potentially undervalued companies with strong economic moats and good management.
